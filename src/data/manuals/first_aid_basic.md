# Basic First Aid for Disaster Response

## 1. Bleeding Control
- Apply direct pressure with a clean cloth.
- If severe, apply a tourniquet above the wound.
- Keep the victim calm.

## 2. Bone Fractures
- Immobilize the affected limb using a splint.
- Do not attempt to reset the bone.
- Check for circulation below the injury.

## 3. Burn Treatment
- Cool the burn with running water for 10-20 minutes.
- Do not use ice, butter, or ointments.
- Cover loosely with a sterile dressing.

## 4. CPR (Cardiopulmonary Resuscitation)
- Check for responsiveness.
- Call for help (or alert on-device SOS).
- Perform chest compressions (100-120 per minute) until professional help arrives.
